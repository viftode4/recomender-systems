| File | Use |
| --- | --- |

Other versioned directories preserve earlier drafts and research supplements.
The [completion checklist](../docs/COMPLETION.md) lists the remaining review
and submission work.

To rerender a preserved archive, use the builder **extracted from that archive**,
as described in [REPRODUCE.md](../REPRODUCE.md). Its hash belongs to that version;
a newer checkout builder is for new reports. Use a new output directory and
keep the published evidence unchanged.
